How to interpret the result

A score is evidence from the current model, not proof of how a recording was made. ACRCloud can return separate original, vocals and accompaniment scores, source probabilities and time segments. It does not disclose which exact spectral artifact or watermark caused a classification.

This application is an independent interface using ACRCloud's authorized API. It is not affiliated with or endorsed by ACRCloud. This module does not modify audio, conceal provenance or invent detection scores.
